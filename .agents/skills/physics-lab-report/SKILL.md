# 大学物理实验报告

## 第 0 阶段｜先要本次实验网站截图和评阅对象

1. 先请用户发本次实验在选课或预约网站上的**详情页截图**，截到实验名称或编号、课程日期时间、地点、任课教师和页面上显示的其他填写要求。已有当次截图就用它。网站无法打开时，请用户提供同次官方详情或逐项确认缺失字段。课表、往年模板或仓库资料只用于核对；遇到冲突请用户确认。
2. 直接问「这份交给哪位老师或助教评阅，还是只给你自己打印用？」用户已明确给出就记下。网站上显示的任课老师不能自动当作评阅人。
3. 新写或实质重写时，把截图核对结果、评阅对象、模板和未齐材料记入工作区的 `brief.md`，参照 [协作记录与准入条件](../personal-writing/references/coauthoring.md)。**对象和本次必要字段未确认前，禁止填写报告或导出提交版。** 等待时可识别截图、查课件、转录数据、列待填栏。现场数据未确认时，禁止写实测结果；现场观察不足时先问本人，再决定哪些能用于误差讨论。

先读用户指定的课程记录或项目下的 .course-context/physics-lab-report.md。用课表核对本次实验名称、日期、时间、地点和教师。写报告时优先用用户提供的当次教师模板、要求和手改稿。用户未提供模板时，直接从相应的内置 Word 副本开始：[预习报告](assets/preview-report.docx) 或 [正式报告](assets/formal-report.docx)。仍按当次明确的栏目和提交要求填写。

长期需求、资料入口和本次现场要求分别记录。可以直接编辑 [课程设置样例](../../../course-context.example.md) 中的栏目并保存到个人项目。详见 [课程资料与偏好记录](../personal-writing/references/course-context.md)。

## 按交付物读完必要材料

| 本次交付 | 开始对应工作前必须打开 |
| --- | --- |
| 空白数据记录表 | [记录表流程](references/record-sheet.md)、本次超星实验课件或当次讲义、教师指定记录页（如有）。核对课表和现场要求；按本次课件反查每个原始量及单位。 |
| 预习报告 | 本次实验课件、当期课表、实际使用的预习 Word 模板。检查综述、重点、难点及各栏字数；一并交记录表时执行记录表流程。 |
| 正式报告 | [正式报告流程](references/formal-report.md)、本次课件、实际使用的正式 Word 模板、本次原始记录和老师的现场要求。计算与修约前打开本学期绪论的对应原页。用户未提供绪论时检查 [随附课件](assets/reference-library/physics-intro-107-slides.pdf) 能否用于当次任务。 |

先在当前项目、课程记录和随附资料中查找。缺本次课件或关键现场记录时，告诉用户具体缺哪份材料，先做可独立完成的模板、栏目或数据转录。把尚待材料的部分标清。旧报告按 [参考库](assets/reference-library/README.md) 查对应实验，只用来核对记录表旁的量级，或寻找可向用户核实的观察线索。

交付 Word 或 PDF 时，若宿主提供相应文档或 PDF Skill，先加载对应流程，用它生成并检查成品。否则使用当前可用的文档能力，核对可打开性、打印版面与输出格式。

第一次选实验、需要从系统里的多项实验中筛选时，可参阅 [作者的优先选课清单](references/course-selection.md)。用户已确定实验时直接使用本次课件。

## 课前：记录表和预习

确认本次用途、实验和当次课件后，按实际操作顺序制作可打印记录表，原始读数留空。新实验或缺本次课件时，提醒用户从超星提供本次 PPT、PDF 或完整截图。仓库旧报告数据只用于记录表旁的可选量级提醒。默认 A4、宋体，工具支持时交付 Word 与打印 PDF。详见 [记录表流程与 CC98 参考用法](references/record-sheet.md)。

做预习报告时，按本次课件和预习模板写实验综述、重点和难点，执行各栏的字数与本次交付要求。讲清仪器读什么、步骤如何衔接、哪些量之后要代入。需要完整预习材料时另附空表。只修改现有预习稿时按指定范围处理。

## 课后：正式报告

收到本次现场原始记录照片或确认过的同次记录后再填实测和结果。对照当次课件、绪论和现场要求，先复核原始表，再计算和修约。缺数据时可以先准备模板和待填栏目。旧报告中的数值、措辞、结论和思考题答案不得作为正式报告素材。CC98 参考只可提示 Agent 向用户核对哪些现象。详见 [现场观察、原始数据与修约](references/formal-report.md)。

交付前执行 [通用用语检查](../personal-writing/references/wording-check.md)，并逐栏检查网站信息、评阅要求和实测证据。正文禁用「根据课件内容」「根据绪论内容」「根据你提供的数据」等话；直接写操作、实测、公式与修约结果。Agent 与用户的问答、个人习惯、内部核对清单及参考资料使用过程留在工作区。
