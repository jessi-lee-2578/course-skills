# 海报样式、出图与修改

## 先让用户给出视觉决定

读作业要求并核对涉及哪一方文明、展览设定、目标观众、交付尺寸与用语。根据材料给两到三个具体方向，每个说明用什么当主视觉、文字怎么排、哪些史实最适合出现在画面上。能提供参考时附可打开的参考链接，说明借鉴的部分。展览海报可比较「馆藏特展：一件实物占主画面」和「考古展板：位置图、年代与少量器物同屏」一类真正不同的方向。

给自己的推荐和理由，请用户明确选一个，再说一句他最想保留的感觉或画面。用户想混搭时复述所选的元素再确认方向。确认前可以查资料、写图文方案和做参考草图；正式生成与排版等用户选择后开始。

| 已有明确提示词，需要通过已配置的生成服务出图 | [JimLiu 的 Baoyu Image Gen](https://github.com/JimLiu/baoyu-skills/blob/main/skills/baoyu-image-gen/SKILL.md)，在环境已有支持的工具或服务时使用。 |

选择与本次任务最贴合的一个创作流程，交给它已确认样式、画幅、主视觉、参考图、保留项、已核实文案和史实约束。以 Agent 当前已加载的 Skill 和已有图像能力为准。无法加载上述 Skill 时可用可访问的说明组织提示词，再交给当前能用的图像工具，例如 [OpenAI Image Generation](https://github.com/openai/skills/blob/main/skills/.system/imagegen/SKILL.md)。上游链接用于发现和查阅，具体安装与后端配置取决于使用环境。没有图像工具时交付构图、制作提示词和可上版文案，并说明进度。

## 出图、校验和返修

- 实物照片或遗址图的图注写清对象和来源。生成图用于气氛、场景或有依据的复原示意，标明其性质。器物造型、服饰、建筑、地理或年代是内容重点时，对照资料检查成图。主标题、日期、专名、图注和较长正文宜独立排版，检查成品里的字、单位和拼写。
- 出一版预览方便用户指出具体区域。反馈明确时从最新预览做局部改动，例如换标题、调整留白、重排图注或修改单个图像区域，同时保留已经选定的风格和其余版块。保留上版便于比对。一个局部编辑若影响对齐、裁切或内容关系，连同这些位置一起复查。
- 用户不满意但原因不明时，把可能的问题定位到具体区域或层次，例如主图像广告片、文字层级不清，或史实看着不对。给出可见的一个差别，请用户说哪里偏离原意。若要改整体视觉方向，回到样式选择，请他确认新方向后再重新生成。史实错误直接回到资料核对，并同步修正文案、图注和插图。
- 导出前根据实际展示场景检查远看可读性、版面边缘和裁切，以及图像与文案的准确性。用户需要展示制作过程时留下实际的选样理由、提示词、初稿和修改前后记录。
