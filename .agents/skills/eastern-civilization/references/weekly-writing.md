# 分周作业、文风与改稿

## 逐题讨论与批量整理

- 以原题核对周次、题号、题干、术语和动作词，保留「比较」「个人观点」「模拟联合国」等限定。「公共 IP」这类原题术语按题干保留。提交周数和原始材料的范围有出入时标出具体哪周，依据当次要求处理。
- 旧研究稿可提供背景和线索。正文优先取最新本人手改稿，其次取最新确认稿。同一份材料中存在旧答案和新题目时分开使用。对照用户明说过的最新写法，尤其留意旧范本中已经被纠正的习惯。
- 对一题，先交代作者为何想到这个角度，用例子和资料推进，再回答题目要求。逻辑链可以先用一句或几个短步骤说明每一步为何接得上。用比较时，明确比较维度和范围。分析因果时写清中间过程。段落如果只增加一个新的问句，继续找这个问题能怎样帮助回答原题。
- 用户提出「成文」时，按 [成文模板](answer-template.md) 写完整答稿并保存到本次工作区，采用约定的文件格式。有明确提交范本时沿用其版式。从正文第一段到结尾逐题检查约 800–2000 字。多题整周整理时，各题分别保留逻辑链与回答，AI 辅助学习说明与参考文献按模板置于周末。
- 批量整理前先列周次、原题数、已确认稿和缺项。生成后逐周核对题数、题干、正文是否完整、引用编号与附录是否对应，抽查换页、图片和版式。某题尚未确认便标在那一题，已定稿的题可以先整理。格式转换产生的检查副本按需要保留在工作区。

## 先学习样稿，再检查 AI 惯用词

1. 优先读作者给的同体裁本人稿、明确认可的段落或同段改稿对。重点看他怎么引入一件事、观点放在哪、例子如何接上、句子多长、怎么表达保留意见。把明显规律配上简短的样稿依据。样稿的史实和个人经历只有本次相关、经过确认才写进新稿。
2. 明确记录作者说过「不要这样写」的措辞，与从样稿推测的习惯区分。没有同体裁样稿时可先用作者的原话；文风很重要且材料不足时，再请他给一小段。用同一题的一小段试写，请作者直接改最不自然的一两句，把改动带进后文。
3. 这门课曾明确纠正以下用法，使用者的最新明确要求优先。拟稿时先按作者自己的表达写。复查时搜索这些词和同类句式，结合上下文修改正文中的自写文字。原题、直接引语、标题和术语按原文保留。

| 曾被纠正的写法 | 改法 |
| --- | --- |
| 在正文习惯性说「我猜」「继续追问」 | 写具体想到什么，按语境用「我想到」「我接着想」「我又想到」。 |
| 用「稍微收了一点」「真正的……」之类的空泛说法承接 | 直接写改变了哪一项判断、这次只讨论什么，或把空话删掉。 |
| 每段先肯定、再用「并不等于」「不能据此认为」反复回撤 | 写作者的判断和理由。证据边界确有影响时，在需要的地方说清它能支持哪个结论。 |
| 把作者的用词擅自加重，或把具体判断润色成含糊的中间立场 | 保留原来力度，例如「削弱控制力」按原意处理；有事实冲突时说明查到什么并一起修正。 |

有的改法可以复用到任何文档，例如先对照同段改稿、搜一遍模型惯用词、区分原话与补写内容。某个词是否合适仍取决于作者、体裁和句子用途。

## 收到修改意见后

- 能定位到具体词句就直接改指定文字，并检查引用与相邻句是否仍然连贯。用本人最新改过的文件作为底稿。本文其他已经确认的段落从当前稿保留。
- 指出「逻辑断了」时，先找前提、案例和结论之间断在哪一步。缺背景就补背景，举例支持了另一件事就换例子或缩小判断，段落顺序不对就调序。修改后再读该段前后各一段。
- 反馈只有「不像我」时，挑一处能指出具体差别的句子，对照样稿；仍有两种理解且会影响整篇时，给他看短片段或问一个具体问题。反复出现的偏差写回文风要求，对受同一问题影响的段落一起核对。
