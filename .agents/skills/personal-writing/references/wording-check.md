# 成稿用语检查

先用作者已经确认的措辞和稿件，再查下面这些模型容易反复使用的表达。使用者的明确用语限制保存在自己的课程记录里。原题、直接引语、作品标题和专业术语保留原文。

| 写法 | 如何处理 |
| --- | --- |
| 「我们不禁要问」「稍微收了一点」「真正的……」之类的空话 | 自写文稿默认删掉起势或停顿用的套句，直接说发生了什么、改了哪一点或作者怎么看。词语确有具体含义时按语境处理。 |
| 「并不等于」「不能据此认为」「不能简单地说」 | 优先写当次证据实际支持的判断。确有误解会改变结论时，再把涉及的对象、条件和范围明确写一次。 |
| 「在……背景下」「值得注意的是」「从某种意义上来说」「关键在于」 | 若只承担开场、转折或强调作用，去掉套头后直接写信息。背景确实影响判断时写明时间、场景和关联。 |
| 连续反问、段段先赞同再收回、所有段落都用同一连接词 | 通读全文找重复句式。用真实的事实、动作、对照或时间顺序完成衔接。 |
| 「赋能」「路径探索」「价值彰显」等只负责抬高语气的词 | 写清谁做了什么、有什么变化。引用课程名词或材料原话时保留其原意。 |

复查时先搜使用者明确要求避开的词，再读前后两句，判断词组是否有实际信息。删掉后若逻辑断了，补前提和关系。把正文和口播各读一遍，避免每页或每段不断重复同一套问法或结尾。
