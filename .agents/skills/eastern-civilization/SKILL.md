# 东方文明史

## 第 0 阶段｜先问谁看、这题你怎么想

**讨论题缺少评阅对象、本人切入点或试写确认时，不得生成完整回答或提交稿。**

1. 评阅对象由用户明确给出。缺失时先问「这份是交给任课老师、助教，还是给同学分享？」受众不因题型自动确定。
2. 每题记录用户已说过的观点。没说过时，必须对着这一道题问一个开放问题，例如「题目里这两种情况，你想先比较哪个差别？」候选思路要经用户选择才算作者观点。批量任务逐题判断，只整理已确认的题。
3. 在工作区按 [协作记录与准入条件](../personal-writing/references/coauthoring.md) 写 `brief.md`，记录每题的切入点、证据和待确认项。等回复时只读题、讲必要背景、查链接、列证据或列提纲。禁止输出答案正文、第一人称判断或可提交的文档。
4. 对象和切入点明确后，发简短逻辑链和最容易写偏的一小段给用户。用户确认或回改后才按成文模板展开。「快一点」「直接给我成品」本身不解锁。只有用户明确放弃询问观点或试写的要求，才跳过对应步骤；评阅对象仍要确认，缺少的作者观点不能代写成用户原意。

先读本次作业要求、原题、课件和用户已经给的想法。在可访问的材料中找最新版手改稿、已确认答案、已交范本和前一次改动记录。原题用来定问题，手改稿用来定正文与文风，已交范本用来定结构。按当前任务选下面的流程，交付前查证本次实际采用的资料。

跨周写作先读用户指定的课程记录或课程项目里的 `.course-context/eastern-civilization.md`。本人确认会长期使用的措辞、样稿和范本入口，当轮实际更新 Markdown。把还需校准的文风观察单列。参见 [课程资料与偏好记录](../personal-writing/references/course-context.md)。

## 每周讨论题与分周作业

先打开 [分周作业、文风与改稿](references/weekly-writing.md)。写完整稿时同时打开成文模板与通用用语要求，交稿前执行各自的检查。 [成文模板](references/answer-template.md) · [通用用语要求](../personal-writing/references/wording-check.md)

1. 用户熟悉题目时，先听他已经想到的联系；陌生时，先给理解原题所必需的背景和少量资料，再问一个能延展其想法的问题。有观点就接着补依据，避免把同一问题换个说法反复问。
2. 把观点、例子和推理顺序列成简短逻辑链。每个主要理由找具体的人物、制度、事件、实物或文本。补足案例与结论之间的解释，发散后回到原题。历史资料中的判断标明出处，第一人称只写用户真正表达过或认可的想法。
3. 通过第 0 阶段后，按 [成文模板](references/answer-template.md) 展开。默认**每题「回答」正文约 800–2000 字**，原题、逻辑链、AI 辅助学习说明和参考资料单独计算。教师或用户当次另有字数要求时按当次要求。
4. 正文通常展开两到三个有实质区别的例子或证据点。写清各自支持哪一步、怎样共同回答原题。比较题按同一维度比较，单案例题可展开同一案例中不同的材料或环节。交稿前逐题核对回答、参考文献及链接。作业要求 AI 辅助学习说明时另附。材料不足时先补查，再把真正缺少的作者观点或证据具体标明。按 [分周作业、文风与改稿](references/weekly-writing.md) 保留作者的判断和写法。

## 史实和链接由 Agent 先核实

用到史实、图源或引文时先打开 [来源核验流程](references/source-checking.md)。正文、海报或展示使用的链接，由 Agent 打开逐条检查。分别记录链接是否抵达正确的来源、实际读到哪一层、那段内容支持哪条主张。给用户能直接点开的来源和定位；用另一款 AI 复核由用户自行选择。

## 展览海报

接到海报任务先打开 [海报样式、出图与修改](references/poster-workflow.md)。由用户确认文明、展出地、受众和用途。先给两到三个具体样式，说明主视觉、排版和取舍，请用户明确选择并说说想法。**用户未确认受众与样式时停在提案阶段，禁止正式出图。** 用户已经明确指定样式并给过想法的，记录其选择后继续；反馈只有「都行」时，给出首选和理由，请他确认。选定后必须走对应的创作流程，并按流程核对、返修。

## 个人 AI 使用展示

只有作业明确要求或用户提出时才附 AI 使用说明。先由用户确认评阅对象和可展示的过程证据。根据真实记录写用过的模型、具体用途、怎样核对来源、自己作出的选择与改动。若要做 PPT，执行 [课堂 PPT](../classroom-presentation/SKILL.md) 的文稿和模板确认步骤。正文不夹带聊天或取材提示；作业明确要求展示协作过程时，另用标明出处的证据节选。
