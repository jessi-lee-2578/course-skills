# 现场观察、原始数据与修约

## 先收本次材料

打开正式报告模板、本次实验课件、当前绪论和现场照片。把用户提供的教师现场要求记在本次工作记录中，包括实际次数、单位、仪器档位或允差、拟合口径、变更后的思考题和交付要求。按明确的现场口径处理。课件与现场说法冲突且会改变结果时，列出具体冲突请用户核对。只回答本学期该次思考题，缺原题时请用户提供。

把照片逐行转录，保留读数单位、正负号和仪器实际位数。把原始读数、零点修正、换算和计算结果分开。遇到模糊读数或复测版本冲突，指出准确行列请用户确认。按模板放入签字原始记录。继续改本人 Word 时保留封面、原有栏目、原始照片和裁剪。

## 从实际观察写误差分析

先看数据哪里有可讨论的变化，再问用户一两件能确认的事，例如「同档卸载读数较高，当时有没有盘子摆动或回程变化？」或「温度示数稳定后，电压还在变吗？」有明确记录就直接用。报告写发生的现象、发生在哪个步骤、可能影响哪个量和理由。误差方向由证据决定。提问过程、协作日志和旧报告内容留在提交物之外。

## 按绪论做不确定度和修约

1. 先定位当前绪论中的仪器限差、A/B 类评定、合成、有效数字和修约页，再对照本次课件和教师要求。优先读取用户提供的当前版。未提供时查个人课程记录或 [随 Skill 提供的绪论课件](../assets/reference-library/physics-intro-107-slides.pdf)，核对适用学期；图片版需查看对应页原图。仍缺当前规则时请用户提供相关页，先做能核定的原始表和中间量，最终修约标为待确认。
2. 核对各分量的来源、量程、单位、分布、换算及独立性条件。区分分辨力、仪器最大允许误差和标准不确定度。按本次采用的模型列出所需分量、公式、代入和传播或合成步骤。
3. 保留中间计算位数，最后才修约。既有课程资料中不确定度首位为 1 或 2 时可保留两位有效数字，首位为 3 或以上时保留一位。按本学期绪论对不确定度单独规定的进位规则执行。测量值按其修约规则（既有课程采用四舍六入五成双）与不确定度末位对齐，科学记数法先统一指数。留必要的修约前后结果和单位。已有记录只作定位，最终以本次绪论原页为准。
4. 逐差列出每组和对应档位。拟合说明输入、横纵轴、单位、方程和斜率怎样换成目标量。更改原始值或零点修正后，同步重算受影响的数表、图和结论。公式字号与正文协调，按模板统一格式。

正式提交前复核图、表、正文、单位与有效位数，检查签字照片位置、裁剪和打印版面。
