# 来源核验

## 打开原页并读到有关的位置

1. 从原题和拟写内容提取可检查的主张。找课程资料、博物馆藏品页、发掘报告、出版物、原机构页面或研究论文。来源的用途要匹配主张，例如藏品页适合查器物资料，名录页可以核对是否列入名录。涉及现状或官方立场时区分事件日期、资料发布日期和核验日期。
2. 对实际引用的每个链接打开原页。追踪跳转，核对页面标题、机构、条目和内容。返回成功但落在首页或登录页的标为未访问到目标。检查 PDF 对应的页码、图表或段落。搜索摘要用于发现出处；只读到摘要、目录、图注或题名时记录实际层级。
3. 用「正文主张｜来源标题和直达链接｜页码、栏目或段落开头｜实际读取范围｜支持情况」记关键证据。原文只支持一部分时缩小表述。只读到档案目录时，按目录能确认的范围写。遇到失效、付费墙或验证码时，查找同作者、同机构的正式备选入口，例如 DOI、开放存档或博物馆替代页。找不到能支持主张的可读依据，标出缺口或从成稿撤下该项。
4. 给用户直接可点开的链接和定位。读者自行复看时，只需查最关键或最有争议的几条。用户若想交另一个 AI 独立复核，可复制同一张主张与原链接表。交付前说明哪些入口未能读到、哪些实际只读了摘要，不以第二次复核替代 Agent 的核对。

## 一个可复查的例子

「联合国教科文组织给出的良渚古城遗址年代约为公元前 3300 年至公元前 2300 年。」可打开 [世界遗产中心条目](https://whc.unesco.org/en/list/1592/)，在页面最前面介绍遗址的位置与年代的段落中定位。该段支持的是遗址的年代范围。如果正文要进一步断言某类器物发源于此，还需要能讨论器物出处和同类遗存的研究证据。
