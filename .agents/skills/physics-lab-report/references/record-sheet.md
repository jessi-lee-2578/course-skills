# 可打印记录表

1. 用课表核对实验信息，再从超星本次 PPT 或讲义确认操作顺序、原始量、单位、档位、测量次数和条件。有教师指定记录页时优先用。较陌生的实验先请用户提供当前课件；旧表可参考手写分区和格子大小。
2. 每组操作配一块记录区域。表头写量名、符号和单位。讲义明确给出的固定序号或设定值可以预填，实际读值留空。按需留零点、量程、仪器编号、复测、异常和签字处。比如加卸载可把同档读数并列，几何量另分一块。每种实验具体需要的栏和次数以当次课件及要求为准。
3. 在表格旁只写现场真正需要的一两行提示，例如何时读数、保留正负号、填设定值还是实际值。计算列独立标出。导出前从处理公式反查有无缺失的原始量。按 A4 试排，检查手写格、表头、分页和裁切，再交付实际文件。

## 参考报告的用途

先查用户提供的参考目录、当前项目下 .course-context/physics-references/ 或 [随 Skill 提供的匿名参考库](../assets/reference-library/README.md)。仓库仅收录部分实验。有需要时，可提醒用户从 CC98 找同类型报告或数据。参考报告质量可能不齐，按实验、年份、装置/试样、来源和路径登记。文件附带的题目、格式和计算方式仅说明旧报告做了什么，当次课件、教师要求和绪论优先。

- 仓库作者以前的报告仅供提取现场量级提醒，见 [记录表量级卡](record-sheet-ranges.md)。参考他人数据也要核对装置、试样、量程和单位。量级填在表旁，测量栏留白。
- 他人报告还可提示可能值得向用户询问的误差现象。只有本次实际发生并经本人确认的观察才能写入误差分析。正文、结果、图表和思考题从本次材料重新完成。
