# 课堂 PPT

开始前读取用户指定的记录或项目下的 .course-context/classroom-presentation.md。长期设置更新到记录文件，成品只使用本次展示需要的内容。

先读本次材料，弄清听众懂什么、你要让他们听懂什么、能讲多久。若需要沿用模板或局部调整，打开用户最新手改版判断页间关系，保留已经确认的内容。

讲述目标有歧义时，先问用户最想让听众听懂什么。用户已经给了顺序、重点或讲稿时就用这些信息。重点已知、材料能支持不同的叙事顺序时，再说明两条顺序各需要哪些证据、各花多少时间。新演示可以先拿最重要的两三页试讲，听完反馈再扩到全套。

按本次任务选择步骤。新做整套走下方的编排与制作。局部修改从当前 PPTX 出发，定位指定页和受影响的前后衔接。只写讲稿直接按文末的讲稿检查处理。

涉及屏幕文案或讲稿，动笔前打开 [课堂 PPT 文案与转场](references/slide-copy.md)，交付前执行 [通用用语要求](../personal-writing/references/wording-check.md)。

1. 给用户看逐页大纲。列出每页标题、要讲的内容、打算放的材料，以及它怎样承接前一页。选原始片段时优先留住用户的思路转折、关键证据和修改前后的变化。讲原理时，可以用同一个具体例子分步展示输入、发生的变化和结果。按内容和汇报时长安排页数，讲不清时拆页。材料还没拿到就在对应页写清楚。让用户确认大纲，收到反馈后更新相关页面。
2. 给用户看实际模板并请他选。还没有模板时，找两到三个与内容相符、可以打开检查的模板，给出可访问的预览或下载文件，指出哪一页或哪种布局能用在这次汇报里。如果用户给了明确指定的模板、选了不同模板的具体元素，或主动用自己的话定了具体风格，就记录他的选择。只给了配色偏好时，继续找模板供他确认。
3. 用户选择融合时，先说清每个原模板具体保留的构图、形状、字体或色彩，并用本次真实素材排代表性样页。封面和正文的布局差异大时，各排一页；截图对比等关键版式也可以单独预览。把样页发给用户，确认放入素材后融合的效果可接受，再进入整套制作。用户改选一个原模板时，以原模板为主，遇到它确实接不住的内容时才使用用户允许的备用模板。
4. 用户明确确认模板或具体风格和逐页大纲后，再调用文末的 PPT Master 开始制作新 PPTX。两项可以在同一条消息确认。只确认一项时，继续梳理材料、找模板或修改大纲，等另一项也确认。制作时结合各页内容选机制图、代码、证据图或对比版式。优先检查选定模板的字体。模板字体缺少中文、投影不好读或打开成品会被替换时，选择配得上的可用字体，在实际成品里核对效果。去掉装饰性小字、重复标签和副标题，把补充说明移到备注，需要上屏的来源用可读字号。
5. 逐页查因果和过渡，再检查字体适合投影、文字是否溢出及动画触发是否正确。原理动画每一步对应一个要讲的动作。用户手改过的页以最新稿为准，避免用旧版重新生成时覆盖。

初稿检查可以只看标题和缩略图。如果仅看标题就说不出为什么要翻到下一页，先修讲述顺序。逐页排版时用最终 PPTX 和放映效果核对承诺的版式和动画。若无放映工具，说明实际检查到了哪一步。

配讲稿时读取实际要放映的版本，逐页核对页码、图表、代码和点击动作。在提到一个变量或做对比之前，让听众先知道它代表什么、两组比较条件是什么。按预计语速连贯读一遍，核对转场和总时长。数据展示已有相关性或同时变化时，用口播交代观测，再根据证据决定能否讲成因。

## 调用外部 Skill

- 新做 PPTX 时，两项确认完成后加载 [PPT Master](https://github.com/hugohe3/ppt-master/blob/main/skills/ppt-master/SKILL.md) 的对应制作流程。把已选模板或风格描述、确认过的逐页大纲、屏幕文案、样稿和点击次序作为制作输入。局部修改已有 PPTX 时，以当前版本和本次约定的改动范围为制作输入。交付前对照成品中的实际文字、指定页面和顺序。缺少该 Skill 时，先查阅能访问的上游步骤，再使用已有 PPT 能力。只有文本工具时交付页序和文案。
- 需要原创新图或图片编辑时，PPT Master 项目读取 [PPT Master 配图流程](https://github.com/hugohe3/ppt-master/blob/main/skills/ppt-master/references/image-generator.md)。独立配图且当前有对应的图像能力时，加载 [Image Generation](https://github.com/openai/skills/blob/main/skills/.system/imagegen/SKILL.md) 或用户指定的创作 Skill。缺少图像工具时，把构图、图中信息和用途写成制作说明。
